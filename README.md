# Omelette Recipe

A clean beginner friendly, semantic HTML webpage built as part of web development practice, providing a simple, step by step guide on how to make a classic homemade omelette.



## Features

- **Semantic HTML5 Structure:** Clear document hierarchy utilizing headings (`<h1>`, `<h2>`), paragraphs, and lists.
- **Recipe Content:** Features a complete breakdown of ingredients (with optional fillings) and detailed, numbered instructions.
- **Media Integration:** Includes high-quality recipe images with descriptive `alt` text for accessibility.
- **External Links:** Links out to favorite culinary resources using `target="_blank"` for safe browsing.
